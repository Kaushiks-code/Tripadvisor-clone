# Tripadvisor-clone

A responsive Tripadvisor-inspired website built using HTML and CSS. This project recreates the main layout of Tripadvisor, including the navigation bar, search section, promotional banner, interest categories, travel destinations, and footer.

## Features

- **Navigation Bar** – Includes the Tripadvisor logo, navigation options, and sign-in button.
- **Search Section** – Search bar with Ask AI and Search options.
- **Promotional Banner** – Green banner with an image, text, and Book Now button.
- **Interest Categories** – Image cards for Outdoors, Food, Culture, and Water.
- **Travel Destinations** – Destination cards featuring popular travel locations.
- **Footer Section** – Includes information columns, app links, currency and country selectors, and social media icons.
- **Sticky Navigation** – Keeps the navbar visible while scrolling.
- **Responsive Design** – Media queries for desktop, tablet, and mobile screens.
- **Hover Effects** – Interactive visual effects on navigation items and image cards.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid and Media Queries
- Google Fonts – Gabarito and Roboto
- Font Awesome

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code or any code editor.
3. Make sure all image files are in the correct folder.
4. Open `index.html` in your browser.
5. For live updates during development, use the Live Server extension in VS Code.
